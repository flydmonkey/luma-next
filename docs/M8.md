# M8：纯音频、DX11 游戏靶与发行冒烟

## 纯音频

API 名称固定为 `capture_mode=audio_only`，WebUI 显示为“录音”。系统声和麦克风可单开或双开，双关仍在 start 前拒绝。本机 OBS `ffmpeg_muxer` 无视频编码器时拒绝启动，因此 M8 采用明确记录的兼容策略：MKV 内包含真实 AAC 音轨和一条 32×32 黑色低码率 H.264 占位视频。UI 显示“纯音频”，不宣称生成无视频容器。stop 必须验证音轨、占位尺寸、文件大小以及 OBS media / wall / ffprobe 时长。

## 可重复游戏靶

`tools/game-capture-probe` 是仓内 GPL 源码构建的 Win32 DX11 swap-chain 动画窗口，不下载第三方二进制。默认回归会构建并启动它，然后把 `Luma DX11 Game Capture Probe` 交给真实 OBS `game_capture`；hook、暂停、成片分辨率和 ffprobe 任一失败都会令脚本非零退出。

```powershell
cargo run -p luma-game-capture-probe
powershell -ExecutionPolicy Bypass -File .\scripts\record-regression.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\record-regression.ps1 -SkipGameProbe
```

探针证明 hook 管线可重复，不替代真实 3A 游戏、独占全屏、多 GPU与反作弊环境手测。

## 发行验收与签名

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\release-smoke.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\release-smoke.ps1 -SkipUninstall
$env:LUMA_CODE_SIGN_CERT='certificate SHA-1 thumbprint'
$env:SIGNTOOL='C:\path\to\signtool.exe'
powershell -ExecutionPolicy Bypass -File .\scripts\pack.ps1 -Sign
```

冒烟顺序为 pack、当前用户安装、HKCU Run 断言、旁路 ffprobe、安装版 audio-only start/stop 以及卸载。`-Sign` 未配置证书时会明确打印 SKIP 且保持未签名；配置后使用 SHA-256 和 DigiCert RFC3161 时间戳，并立即 `signtool verify /pa`。默认包保留 ffplay；`-SkipFfplay` 可省略它，ffmpeg/ffprobe 永远保留。
