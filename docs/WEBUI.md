# 正式 WebUI 迁移说明

正式 UI 是对旧 `Record.App/MainWindow.xaml` 使用体验的 Web 重写，不是 WinUI/C# 迁移，
也没有采用营销站页面。页面资产位于 `web/`，由 `luma-engine` 编译内嵌并托管：

- `/#/`：录制状态、五种模式、快捷设置与开始/停止。
- `/#/library`：录像列表、打开目录与安全删除。
- `/#/settings`：输出目录和当前可兑现的录制默认值。
- `/dev`：保留的 M2 诊断页，不是默认产品入口。

WebUI 直接运行在系统默认浏览器中；录制/片库/设置使用本地 hash 路由，页面不访问
远端资源。原 WebView2 自绘标题栏方案已经废弃。

## 能力呈现

只有“显示器 / 主显示器 + 系统声 + 1080p30 x264”可点击开始。区域、窗口、游戏、
纯音频与麦克风显示“尚未接入”。编码器下拉只列出 libobs 实际探测可用的 H.264
编码器，不可用项在只读区说明；录制状态显示实际 encoder 与降级结果。这既保留旧版产品的
心智模型，也确保 UI 不会向当前引擎发送无法兑现的成功请求。
