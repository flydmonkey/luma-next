# M3：片库、设置与可重复回归

状态：完成。

## API

所有接口继续使用 `{ok,data,error}` 信封：

- `GET /api/v1/library`：列出当前输出目录中的 MKV/MP4/MOV，返回文件名、绝对路径、
  字节数、mtime 与可探测时长。
- `DELETE /api/v1/library/{id}`：只接受单个录像文件名；拒绝分隔符、路径逃逸、
  非录像扩展名和不在输出目录直属层级中的文件。
- `POST /api/v1/library/open`：在 Explorer 打开实际配置的输出目录。
- `GET/PUT /api/v1/settings`：读取或原子替换 `%APPDATA%\LumaNext\settings.json`。

设置结构包含 `output_directory`、`record_system_audio`、`record_microphone`、
`quality` 和 M4 增加的 `encoder`。系统声关闭、麦克风开启或非 `1080p30` 返回 422，防止配置
看似保存却无法兑现。start 可覆盖同名参数，但同样会拒绝未实现模式或能力。

## 回归

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\record-regression.ps1
```

脚本探活并按需隐藏启动引擎，录制至少 20 秒，停止后独立调用 ffprobe 检查视频流、
音频流、合理分辨率、文件大小以及媒体时长与墙钟时长。任一条件失败均以非零退出。
若引擎已由开发者启动，可加 `-EngineAlreadyRunning`。建议人工让 Chrome 播放动态有声
视频作为硬案例；脚本本身不自动控制第三方应用。
