# M6：区域、多显示器、暂停与全局热键

M6 在同一套 libobs session 上增加显示器枚举、单显示器区域裁剪、OBS 原生暂停和
Windows 全局热键。HTTP、WebUI、托盘与热键不维护各自的录制状态。

## API

- `GET /api/v1/targets` 的 `displays` 返回真实 OBS `monitor_id`、名称、虚拟桌面
  `x/y`、宽高与 `primary`。
- `POST /api/v1/session/start` 支持 `mode: "display" | "window" | "region"`、
  `display_id` 与 `region: {x,y,width,height}`。
- `POST /api/v1/session/pause` 与 `/resume` 切换 `recording` / `paused`。
- session 返回 `paused`、`display_id`、`region`；暂停期间 OBS 媒体时间冻结。

区域坐标使用 Windows 虚拟桌面坐标。第一版区域必须完整落在所选的一块显示器内、
至少 32×32，宽高向下做偶数对齐；跨屏区域会在 start 前以 422 拒绝。成片画布等于
裁剪区域尺寸。WebUI 的框选层是按所选显示器等比映射的全屏浏览器地图；取消不会
修改 settings，确认才写入当前选择。

暂停使用 `obs_output_pause`：暂停段不进入成片有效节目时间，`media_elapsed_seconds`
与 UI 计时冻结；`wall_elapsed_seconds` 同样表示扣除暂停段的有效录制墙钟。paused
状态可直接 stop，仍执行 ffprobe 校验。

## 热键与托盘

- `Ctrl+Shift+R`：开始 / 停止。
- `Ctrl+Shift+P`：暂停 / 恢复。

热键注册在托盘 Win32 消息线程，触发 Engine 的同一路径。组合键被其他程序占用时，
启动日志会写明注册失败，HTTP 与托盘仍可用。`--no-tray` 不创建消息线程，因此也不
注册热键；`--no-hotkeys` 可保留托盘而关闭热键。

## 回归

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\record-regression.ps1
# 仅跑旧路径时可显式跳过 M6 用例
powershell -ExecutionPolicy Bypass -File .\scripts\record-regression.ps1 -SkipM6
```

默认 M6 回归增加 640×360 区域录制、暂停 5 秒，以及存在第二块屏幕时的非主屏录制；
单屏机器会明确打印 multi-monitor skip。区域断言成片分辨率，暂停断言媒体钟冻结且
成片时长不包含暂停等待。

## 已知边界

区域框选由浏览器对显示器坐标做比例映射，不是覆盖其他应用的原生透明窗口；精确值
仍可通过 API 提交。显示器热插拔后应刷新目标并重新选择。游戏捕获、纯音频与摄像头
仍未接入。
