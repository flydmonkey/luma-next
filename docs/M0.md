# M0 HTTP 控制面

状态：完成。

- `luma-engine` 默认监听 `127.0.0.1:18765`。
- `GET /api/v1` 返回产品与控制能力探针。
- `GET /api/v1/session` 返回 `idle` 会话占位。
- 两个接口均使用旧 Luma 兼容信封 `{ok,data,error}`。
- 本阶段不初始化或链接 libobs。

```powershell
cargo test -p luma-engine
cargo run -p luma-engine

curl.exe http://127.0.0.1:18765/api/v1
curl.exe http://127.0.0.1:18765/api/v1/session
```
